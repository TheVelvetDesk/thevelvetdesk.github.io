# Fancy Components reference

- Live catalog: https://fancycomponents.dev
- Documentation: https://fancycomponents.dev/docs/introduction
- Source: https://github.com/danielpetho/fancy
- License: MIT

Fancy Components is a source-first collection of animated React components and microinteractions. Its documented stack is React, Tailwind CSS, and Motion, with shadcn-style registry installation.

Strong candidates for future flagships:

- Stacking cards for case studies or service narratives
- Variable-font cursor proximity for expressive display type
- Text reveal/highlighter effects for campaign moments
- Drag, gravity, and cursor-attractor interactions for playful brands
- Lightweight animated backgrounds where custom WebGL would be excessive

Integration rule: choose one expressive effect per viewport, retokenize it to the project, audit its dependencies, preserve reduced-motion behavior, and keep dense copy on calm surfaces.
